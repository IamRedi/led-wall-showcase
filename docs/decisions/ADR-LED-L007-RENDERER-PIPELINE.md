# ADR-LED-L007 — Renderer pipeline: heritage renderers behind the semantic state, deterministic palette, data-driven expressions

- **Status:** ACCEPTED (implementation-level architecture decision for LED-L007; recorded by the executor during the Owner-authorized 2026-09-14 milestone; the milestone itself awaits independent review and Owner acceptance)
- **Context:** The accepted LED-L002/003 firmware tracks every semantic program but renders a safe blank frame for all non-idle programs (`Runtime::render_frame_()` stub). The frozen specification already defines the visual behavior (§6 text contract, §7 registry, §8 expression mapping, §12 render reliability, §24 gate lines), and the heritage `PLUTO EQ ACCESSORY` sources define the verified algorithms. The Owner authorized one end-to-end milestone (Visual Renderers + Text Pipeline) with a strict no-hardware boundary, so every renderer had to be host-testable with golden frames before any device involvement.
- **Decision:**
  1. **Layering (preserved):** semantic state → renderer selection → `FrameBuffer` → `led_driver` → frame throttle → output. The renderer reads the `ModeMachine` snapshot (current program = transient if active, else base — §11 as the sole source of visual truth), owns no program state, parses nothing, knows nothing about HTTP/WS/HA/HUGO, and cannot bypass the brightness ceiling (brightness applies below the framebuffer in the driver).
  2. **Heritage mapping:** the 8 registered animations are COPY (corners, checker, row_sweep, bounce) or COPY/ADAPT (border pulse, rain, wave/plasma parameterizations) of the heritage demo algorithms; the text renderer is the INHERITED heritage `drawChar/drawString/stringWidth` + scroll model `offset(t) = (t/speed) % (w+30) − w` at anchor y=2; the glyph table COPYs the panel-verified `glyphCols` data byte-for-byte and extends it with NEW standard 5×7 patterns to cover the frozen §6 guaranteed set (A–Z, 0–9, space, `- . !`); the heritage box-fallback for unknown characters is superseded by the §6 space + `skippedCharacters` rule. The unused heritage `font5x7.h glyphRows` data is not adopted (never panel-verified, not a coherent 5×7 encoding; its kWidth/kHeight constants are). Heritage demos not registered: scroll demos are superseded by the semantic text pipeline, carousel is non-semantic per §7, spectrum/mic are conditional (ADR-012) and stay unimplemented/unadvertised.
  3. **Determinism:** renderers are pure functions of (program, program-relative time). Heritage `random8()` rain state is replaced by a fixed index-derived per-column cycle (documented ADAPT — the contract requires determinism for the same state/time input). Time sources are program start stamps recorded additively by the `ModeMachine` (wrap-safe unsigned differences; heritage `frameMs` model).
  4. **Deterministic palette:** renderers express the heritage CHSV colors through an integer-only 6-sector HSV→RGB conversion and a 256-entry `sin_u8` table replacing FastLED's device-only `sin8`/`beatsin8`/rainbow conversion, so host golden frames and device output are identical by construction. Heritage hue/sat/val arguments are preserved; exact RGB output may differ from the heritage panel appearance (internal per §3).
  5. **Expressions:** data-driven mapping table (`effects/expression_map.h`) — no expression state machine. Frozen spec examples implemented exactly (thinking→slow wave, alert→red border pulse, sleeping→dim idle/rest); the remaining intents map to existing canonical renderers with distinct parameters (listening→calm border pulse hue 160, speaking→fast warm wave, happy→slow plasma, error→static red border, idle→rest/blank). The table is versioned data per §8; it is not config-overridable in v1 (no new config surface is opened by this milestone).
  6. **Renderer-reserved truth:** `textTooWide` is enforced at command acceptance (scroll:false + width > 30 px ⇒ typed error, no mutation); the `display.text.show` ack reports `skippedCharacters`; `text.done` is emitted once per program activation (static: first shown frame; scroll: one full traversal) through the existing bounded EventSink. `fwVersion` bumped to 0.1.0-alpha.3; a pre-existing divergence (GET /state reported a stale default firmware version while GET /identity reported the current one) is fixed in the same path.
- **Alternatives considered:** adopting FastLED's HSV→rainbow conversion bit-exactly on host (rejected: not reproducible reliably and device-only); keeping the heritage minimal glyph table with box fallback (rejected: contradicts the frozen §6 supported-set guarantee); auto-scrolling wide static text (rejected: §6 fixes the textTooWide error + retry contract); spectrum/paint renderers now (rejected: conditional capabilities, ADR-012, explicitly out of the authorized scope).
- **Consequences:** the device renders the frozen visual behavior deterministically and stays fail-closed (unknown/unrenderable ⇒ safe blank); all visual behavior is host-verifiable; physical appearance/orientation/brightness claims remain §22 hardware gates. Static frames never re-show (dirty-flag), animated programs re-render strictly through the accepted 50 ms throttle.
